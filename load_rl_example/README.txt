The files in this directory are related to data/moeller_ag_v5.json Use Case!

- model.checkpoint:         RL MuZero Model created on 2025-09-16
- observation_config.json:  Configuration of observation space used during training of this exact model
- action_config.json:       Configuration of action space used during training of this exact model
- algorithm_params.json:    Parameters and architecture of the RL model itself -
                            num_simulations was 500 during training, but for inference 10 is set to make it faster
- HTML files:               Can be opened in a browser of your choice to visualize the RL-generated schedule
